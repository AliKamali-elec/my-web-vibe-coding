# 🚀 Ali Kamali - Personal Portfolio

A modern, animated personal portfolio website built with React, Vite, and Framer Motion. Features a dark theme with purple accents and smooth animations.

![Portfolio Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![React](https://img.shields.io/badge/React-18.3-61DAFB?logo=react) ![Vite](https://img.shields.io/badge/Vite-5.4-646CFF?logo=vite) ![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-38B2AC?logo=tailwind-css)

## ✨ Features

- **Dark Theme** - Easy on the eyes with purple accent colors
- **Smooth Animations** - Powered by Framer Motion
- **Responsive Design** - Works on all devices
- **Real Projects** - Showcases actual GitHub repositories
- **Typing Effect** - Dynamic hero section
- **Scroll Animations** - Elements animate as you scroll
- **Contact Section** - Easy ways to reach out

## 🛠️ Built With

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **GitHub Pages** - Deployment

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/AliKamali-elec/my-web-vibe-coding.git

# Navigate to directory
cd my-web-vibe-coding

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🚀 Deployment

The site is deployed on GitHub Pages at:
**https://alikamali-elec.github.io/my-web-vibe-coding/**

To deploy updates:
```bash
npm run deploy
```

## 🎨 Customization

### Colors
Edit `tailwind.config.js` to change the color scheme:
```javascript
colors: {
  primary: {
    // Your accent colors
  }
}
```

### Content
- Update project data in `src/components/Projects.jsx`
- Modify skills in `src/components/Skills.jsx`
- Change personal info in `src/components/About.jsx` and `src/components/Hero.jsx`
